# Quick Plan: Fix Agent DB Pool & AcquireHelper Fallback in Nexus Agent

## Description
Resolve `'NoneType' object has no attribute 'fetchrow'` error in `POST /api/maas/:merchant_id/transact` by properly initializing the database pool in the `nexus-agent` FastAPI server (`server.py`), adding automatic pool fallback in `DeterministicPipelineRunner`, and making `_AcquireHelper` in `catalog.py` and `razorpay.py` auto-resolve `get_pool()`.

## Tasks
1. Update `nexus-agent/nexus_agent/api/server.py`: initialize `db_pool = await get_pool()` in lifespan, attach to `runner`, and close on shutdown.
2. Update `nexus-agent/nexus_agent/pipeline/runner.py`: add automatic pool acquisition in `execute()` if pool is not set on runner or context.
3. Update `nexus-agent/nexus_agent/tools/catalog.py`: enhance `_AcquireHelper` to fall back to `get_pool()` if `pool_or_conn` is None.
4. Update `nexus-agent/nexus_agent/tools/razorpay.py`: enhance `_resolve_adapter` to fall back to `get_pool()` if `pool` is None.
5. Verify with existing pytest test suite in `nexus-agent`.
6. Verify end-to-end via cURL `transact` call against `localhost:3000`.
