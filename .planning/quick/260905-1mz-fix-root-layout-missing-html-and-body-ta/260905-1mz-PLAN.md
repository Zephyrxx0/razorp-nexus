# Quick Plan: Fix Root Layout Missing HTML and Body Tags

## Description
Next.js App Router requires a root layout at `src/app/layout.tsx` containing `<html>` and `<body>` tags. Currently, only `src/app/dashboard/layout.tsx` exists, leading to the error `The following tags are missing in the Root Layout: <html>, <body>`. Furthermore, `globals.css` is not imported anywhere, and accessing `/` results in a 404 because `src/app/page.tsx` is missing.

## Tasks
1. Create `src/app/layout.tsx` with:
   - `<html>` and `<body>` tags.
   - Dark theme styling class (`dark`).
   - Import of `@/app/globals.css`.
   - Metadata for the Nexus platform.
2. Create `src/app/page.tsx` with:
   - Server-side redirect from `/` to `/dashboard/transactions`.
3. Verify:
   - `npm run build` succeeds without missing tag errors.
   - `npm test` continues to pass.
