<threat_model>
ASVS Level: 1
Block on: high severity threats

- Threat T-05-07: SSRF (Server-Side Request Forgery) or path traversal via proxying untrusted `node_id` parameters to the internal FastAPI service.
  - ASVS Control: V5.1.1 (Input Validation - path parameters), V12.6.1 (SSRF Protection).
  - Mitigation: `src/app/api/trust/node/[node_id]/route.ts` validates and URL-encodes the `node_id` parameter. The backend target URL is strictly hardcoded to `process.env.TRUST_GRAPH_URL || 'http://127.0.0.1:8001'` and rejects arbitrary protocol or host manipulation.

- Threat T-05-08: Client-side denial of service via oversized graph rendering or CPU starvation during force-directed layout computation.
  - ASVS Control: V13.1.1 (Denial of Service - resource bounds).
  - Mitigation: Cytoscape `cose-bilkent` layout execution is bounded with a maximum iteration limit (numIter: 1000) and layout animation disabled during initial load (`animate: false`). Node counts are clamped to the top 200 entities if the graph exceeds demo bounds.
</threat_model>

<action>
1. Implement `src/app/api/trust/graph/route.ts`:
   - `GET`: Fetches from `${TRUST_GRAPH_URL || 'http://127.0.0.1:8001'}/trust/graph` with `cache: 'no-store'`.
   - Returns `{ elements: { nodes: [...], edges: [...] } }`.

   - `GET`: Fetches from `${TRUST_GRAPH_URL || 'http://127.0.0.1:8001'}/trust/rings`.

   - `GET`: Validates and encodes `node_id`. Fetches `${TRUST_GRAPH_URL || 'http://127.0.0.1:8001'}/trust/node/${encodeURIComponent(node_id)}`.
   - Returns node details: entity type, current trust score, degree, neighbor entities, and associated transaction history.
4. Implement integration tests in `test/trust-proxy.test.ts` verifying:
   - Successful proxying of graph, rings, and node requests.
   - 502 Bad Gateway fallback when microservice is unreachable.
   - Input sanitization on `node_id` path parameter.
</action>

1. Implement `src/components/dashboard/cytoscape-graph.tsx`:

   - Accepts props: `elements`, `highlightedRingId`, `onNodeClick`, `selectedNodeId`.
   - Applies force-directed physics layout (`cose-bilkent` or `cose` fallback):
     - `nodeRepulsion: 4500`, `idealEdgeLength: 60`, `animate: false`.
   - Configures Cytoscape node stylesheet:
     - Normal nodes: Zinc / Emerald (#10b981) for score >= 70, Amber (#f59e0b) for 40-69, Red (#ef4444) for < 40.
     - Ring nodes: Glowing red halo, bold border, and higher z-index.

   - Slide-over `Sheet` displaying:
     - Entity ID & Type (`email_hash`, `ip_subnet`, `device_id`).
     - Trust Score Gauge with decision indicator (`ALLOW`, `REVIEW`, `DENY`).
     - Fraud Ring Membership status (e.g. "Ring #1 — Multi-Merchant Attack").
     - Connected Neighbors count and 1-hop neighbor list.
     - Associated transactions with links to open the transaction audit drawer.
3. Implement `src/app/dashboard/trust-graph/page.tsx`:

     - Ring Filter Dropdown (`Select`): "All Entities" or select specific detected fraud ring.
     - "Highlight Rings" toggle switch: instantly dims non-ring nodes and colors ring clusters.
     - Graph Stats Pills: Total Entities, Co-occurrence Edges, Detected Rings Count.
     - "Reset Camera" button.
   - Empty State: Renders "No entity nodes discovered" card with explanation when graph is empty.
4. Implement component tests in `test/trust-graph.test.tsx` verifying:
   - Dynamic client mount without server rendering crash.
   - Ring highlight filter applies styling classes to ring nodes.
   - Node click opens the Node Inspector Sheet.
