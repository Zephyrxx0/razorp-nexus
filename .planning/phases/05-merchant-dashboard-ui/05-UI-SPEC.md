## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #09090b | Background, dark canvas surfaces, app shell |
| Secondary (30%) | #18181b | Cards, sidebar navigation, table headers, drawer panels (borders #27272a) |
| Accent (10%) | #10b981 | Primary action CTAs, active navigation indicators, ALLOW trust badges |
| Destructive | #ef4444 | Revoke token, delete product, DENY fraud ring alerts |

Accent reserved for:
- Primary CTA buttons: "Save & Connect Razorpay", "Add Product to Catalog", "Trigger Sample Transaction"
- Active navigation tab underline and selected merchant indicator
- Trust score ALLOW pill badges (score >= 70) and "Hash Chain Verified" shield badge

Destructive reserved for:
- "Revoke MaaS Token" action in Settings
- "Delete Product" confirmation in Catalog
- Trust score DENY pill badges (score < 40) and highlighted fraud ring cluster nodes

Secondary status color (Review / Warning):
- #f59e0b (Amber 500) reserved exclusively for REVIEW trust badges (score 40-69) and transient reconnect toasts.
